# 1차시 픽셀 실험실

중학교 정보 Ⅱ. 데이터 1/12차시 수업용 시뮬레이션입니다. 아날로그와 디지털의 차이, 측정 간격·해상도에 따른 정보 손실과 데이터량을 직접 실험합니다.

**바로 가기: https://cs196083.github.io/pixel-lab-sim/**

**픽셀 모자이크 퀴즈만 보기: https://cs196083.github.io/pixel-lab-sim/mosaic.html**

## 구성

1. 픽셀 퀴즈: 모자이크 그림을 강·중·약 단계로 보며 맞히기
2. 픽셀 돋보기: 칸 수와 색 깊이를 바꾸며 RGB 값과 데이터량 확인
3. 측정 간격: 간격과 기록 단위에 따라 판단이 달라지는 과정 관찰 (가상의 기온 자료)
4. 픽셀 사인: 사인을 큰 칸과 작은 칸으로 칠해 비교
5. 3문장 정리: 빈칸 채우기, 목적별 해상도 선택, 활동 기록 복사

학생의 답은 각자의 브라우저에만 저장되며 서버로 전송되지 않습니다.
